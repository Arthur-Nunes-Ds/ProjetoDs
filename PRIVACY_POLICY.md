EchoDE – Aplicativo de Monitoramento de Consumo Sustentável
Versão 1.0 – 2026

1. INTRODUÇÃO

A EchoDE Ecologic Tech (“nós”) valoriza a privacidade dos usuários (“você”) e está comprometida com a proteção dos dados pessoais, em conformidade com a Lei Geral de Proteção de Dados (LGPD – Lei nº 13.709/2018).

Esta Política de Privacidade descreve como coletamos, usamos e protegemos suas informações ao utilizar o aplicativo EchoDE.

2. DADOS COLETADOS

    Podemos coletar os seguintes tipos de dados:

    2. 1. Dados fornecidos pelo usuário
        - Nome
        - E-mail
        - Informações inseridas no app (ex: consumo de água, energia, materiais)
    2. 2. Dados coletados automaticamente
        - Dados de uso (interações no app)

3. FINALIDADE DO USO DOS DADOS

    Os dados coletados são utilizados para:

    - Fornecer e melhorar o funcionamento do aplicativo
    - Gerar relatórios e análises de consumo
    - Personalizar a experiência do usuário
    - Enviar comunicações (quando autorizado)
    - Garantir segurança e prevenir fraudes

4. COMPARTILHAMENTO DE DADOS

    Seus dados não serão vendidos.

    Podemos compartilhar dados apenas nos seguintes casos:

    - Cumprimento de obrigação legal
    - Requisição de autoridades competentes
    - Prestadores de serviço (ex: hospedagem), sob confidencialidade

5. ARMAZENAMENTO E SEGURANÇA

    Adotamos medidas técnicas e organizacionais para proteger seus dados contra:

    - Acesso não autorizado
    - Perda
    - Alteração indevida

No entanto, nenhum sistema é totalmente seguro. Em caso de incidente, notificaremos as autoridades e os usuários afetados conforme exigido por lei. 

6. DIREITOS DO USUÁRIO (LGPD)

    Você tem direito a:

    - Acessar seus dados
    - Corrigir dados incompletos ou incorretos
    - Solicitar exclusão dos dados
    - Revogar consentimento
    - Solicitar portabilidade

7. RETENÇÃO DE DADOS

    Os dados serão armazenados pelo tempo necessário para:

     - Cumprir as finalidades desta política
     - Atender obrigações legais

    Após isso, poderão ser excluídos ou anonimizados.

8. COOKIES E TECNOLOGIAS

    O aplicativo pode utilizar tecnologias semelhantes a cookies para melhorar a experiência do usuário.

9. ALTERAÇÕES NESTA POLÍTICA

    Esta Política pode ser atualizada a qualquer momento.

    O uso contínuo do aplicativo após alterações implica concordância com os novos termos.
